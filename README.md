# Portefólio — Jaime de Leite Zandamela

Portefólio pessoal em HTML, CSS e JavaScript, preparado para publicação no GitHub Pages.

## Antes de publicar

1. Substituir `YOUR-GITHUB-USERNAME` em `index.html` pelo username real do GitHub.
2. Colocar screenshots em `assets/img/`.
3. Substituir os blocos `COLOCAR SCREENSHOT...` pelas imagens reais.
4. Rever descrições e links de repositórios/demonstrações.
5. Publicar o repositório através de GitHub Pages.

## Estrutura

- `index.html` — página principal
- `style.css` — estilos
- `script.js` — interacções
- `projects/` — páginas individuais dos projectos
- `assets/img/` — screenshots e imagens

## Regra de segurança

Não publicar dados pessoais de terceiros, credenciais, código confidencial ou screenshots contendo informação privada. Para projectos empresariais/académicos, usar apenas material que possa ser tornado público.
